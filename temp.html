We are striving to create a platform where tuned agents can simultaneously work together - creating and integrating all aspects of game development in one workflow.

However, we are not just trying to serve game developers. We believe that by getting AI to overcome the struggles of game development, we can thereby build the blueprint and foundation of multimodal AI.

Founded and built by Sadiq Rasheed, a second-year UGA student, with support from the UGA LLM Lab and its director, Tianming Liu.

Coding was only half the problem

Generating one asset was never the hard part. The hard part is coordinating many. A sword is a model, a texture, an animation, a sound, a damage rule, and a network boundary - six outputs that only count as finished if they agree with each other.

Game development is the clearest place that limitation shows up, which makes it the right place to attack it first. Solving it there produces a blueprint for multimodal AI more broadly - the same question the lab studies from the model side.
